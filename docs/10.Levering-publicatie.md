Levering
========

Dit hoofdstuk beschrijft hoe een dataproduct gebaseerd op IMEV wordt aangeleverd of gepubliceerd.

IMEV gegevenskoppeling van het REV loopt via de REV REST-API. Deze API bevat een Open-API-specificatie (OAS) en is gebaseerd op het IMEV en volgt de
Nederlandse standaard (de API strategie en DSO aansluitvoorwaarden). De API heeft de endpoints voor het toevoegen, bewerken en ophalen van data in het REV.

De Open-API-specificatie beschrijft alle verzoeken die via de REST-API gestuurd kunnen worden en is beschreven in een Yaml bestand. 
De API-specificatie verwijst naar het JSON-schema. Hierin is vastgelegd welke objecttypen, attributen en relaties volgens het IMEV voor mogen komen in de aanleverbestanden.
Naast het schema en de API-specificatie zijn er ook JSON-voorbeeldbestanden voor de aanlevering gepubliceerd.

Het schema en de voorbeeldbestanden zijn per versie te vinden via [deze link](https://register.geostandaarden.nl/jsonschema/imev/). 
Op dezelfde plek is ook een voorbeeld van een API-specificatie te vinden in de map '/OAS' en is niet hetzelfde als die van het REV REST-API.
Voor een API-specificatie zijn er meerdere mogelijkheden, afhankelijk van de functionele wensen. 
In het schema en de voorbeeldbestanden kunnen meer velden voorkomen dan er in de UML-diagrammen staan, omdat ze niets conceptueels of logisch toevoegen aan het model, maar alleen gebruikt worden voor technische implementaties. 
Dit geldt bijvoorbeeld voor de velden "entityType" en "id" in het ExterneVeiligheidsObject.

Nadere details en instructies voor de API koppeling met het REV zijn gepubliceerd in het document REV Aanleverinstructie (zie [www.registerexterneveiligheid.nl](https://www.registerexterneveiligheid.nl) ).
